How to Publish Updates

Because our site is static, each post lives in a Markdown file committed to GitHub. Editors can add new stories by copying the _posts template in the repository and opening a pull request. Once merged into main, GitHub Pages rebuilds the site automatically.

Prefer a CMS-like workflow? Connect our repo to Forestry, Netlify CMS, or CloudCannon for visual editing without leaving the browser.

Organizing Tags

Use consistent tags such as events, fundraising, volunteers, advocacy, and school-news to help families filter updates quickly.

For GitHub Pages sites built with Jekyll, include categories: or tags: in front matter so posts automatically populate tag indexes.
