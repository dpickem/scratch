Stay Synced

Add the PTA calendar to your device so you never miss a meeting, spirit night, or deadline. Choose the option that fits your workflow:

  • Subscribe to our Google Calendar: calendar.google.com
  • Download the iCal feed: basic.ics
  • Import into Outlook: Use the same iCal link or shareable URL above.

Embed the Calendar

GitHub Pages supports embedded iframes. Add your Google Calendar embed code below to display events directly on this page.

Example snippet: 

<iframe src="https://calendar.google.com/calendar/embed?src=yourcalendar@group.calendar.google.com" style="border:0" width="100%" height="600" frameborder="0" scrolling="no"></iframe>

Automated Reminders

Use third-party tools to send reminders without adding server-side code:

  • SignUpGenius: Manage RSVPs and automatic reminder emails.
  • Eventbrite: Issue digital tickets and track attendance.
  • Google Forms + Apps Script: Trigger confirmation emails when a form is submitted.

Tip

Link to external registration forms rather than embedding complex scripts. This keeps the static site light while still offering rich functionality.
