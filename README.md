# Summit Ridge PTA Website

This repository contains a static, GitHub Pages–ready website for the Summit Ridge Parent Teacher Association. The site provides a modern, responsive experience and includes dedicated pages for leadership, membership, news, events, media galleries, donations, volunteer signups, resource documents, and social connectivity.

## Structure

- `index.html` – Hero landing page with highlights and quick links.
- `leadership.html` – Board and committee chair profiles.
- `membership.html` – Membership benefits, dues, and newsletter options.
- `news.html` – Announcements/blog layout with tagging guidance.
- `events.html` – Event listings, RSVP links, and calendar integration tips.
- `gallery.html` – Photo showcase with external hosting suggestions.
- `donate.html` – Online and offline giving instructions plus sponsor tiers.
- `volunteer.html` – Volunteer opportunities and signup tools.
- `documents.html` – Document library for minutes, forms, and bylaws.
- `social.html` – Social media embeds, newsletter signup, and contact info.
- `assets/main.css` – Global styling.
- `assets/js/main.js` – Mobile navigation script.
- `assets/images/` – Placeholder SVG imagery for the gallery.

## Local Preview

Open any HTML file directly in a browser or use a lightweight server, for example:

```bash
python -m http.server 4000
```

Then visit <http://localhost:4000>.

## Deploying to GitHub Pages

1. Push the `main` branch to GitHub.
2. In the repository settings, enable GitHub Pages and choose the `main` branch as the source.
3. Updates deploy automatically on each commit.

## Contributing

- Update page content directly in the relevant HTML file.
- Keep navigation links consistent across pages.
- Optimize images before adding them to `assets/images/`.
- Use descriptive commit messages for future reference.

For questions or access requests, contact the web team at `webmaster@summitridgepta.org`.
